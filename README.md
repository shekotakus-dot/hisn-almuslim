# حصن المسلم — تطبيق أذكار بالسنة

هذا المشروع عبارة عن React + Vite، ومهيأ للتحويل إلى Android عبر Capacitor.

## التشغيل على الكمبيوتر
```bash
npm install
npm run dev
```

## بناء نسخة الويب
```bash
npm run build
```

## تجهيز Android
بعد تثبيت Node.js وAndroid Studio:
```bash
npm install
npx cap add android
npm run build
npx cap sync android
npx cap open android
```
ثم من Android Studio اختر Build > Generate Signed Bundle / APK.

## المزايا
- أذكار الصباح والمساء والنوم وبعد الصلاة.
- عداد لكل ذكر مع حفظ التقدم في localStorage.
- المفضلة.
- بحث داخل الأذكار.
- مشاركة الذكر.
- وضع ليلي/نهاري.
- حجم خط قابل للتغيير.
- نطق صوتي باستخدام SpeechSynthesis في الجهاز/المتصفح.
- اهتزاز عند الضغط عند دعم الجهاز.
- تصميم متجاوب للهاتف.
- مصادر الحديث ظاهرة لكل ذكر، مع تنبيه عند وجود خلاف في التصحيح.

## ملاحظة شرعية
تم اختيار نصوص مشهورة من الأذكار الواردة في كتب الحديث، لكن درجات الأحاديث ليست واحدة؛ لذلك لا ينبغي اعتبار التطبيق مرجعًا نهائيًا للتخريج. راجع أهل العلم عند الحاجة.
